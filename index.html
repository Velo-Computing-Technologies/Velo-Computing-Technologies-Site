Krytonum OS

Velo Computing Technologies | Github

Krytonum is a long-term research project focused on bare-metal x86_64 system architecture and low-overhead kernel primitives.

Status: Pre-alpha / Non-functional. The codebase currently consists of layout skeletons, build system configurations, and driver stubs. This is a multi-year initiative (est. 5-10 years) and is not yet bootable.

Development Roadmap

  • Phase 1: Toolchain stability, Limine bootloader integration, and physical namespace migration (from OrionOS).
  • Phase 2: Virtual memory structures, physical page allocators, and interrupt dispatch handling.
  • Phase 3: Native PCI bus enumeration and low-level hardware IO ring drivers (Intel e1000).

Build Environment

Freestanding cross-compilation requires nasm, a target x86_64-elf-gcc environment, and GNU make.

$ git clone --recursive https://github.com
$ cd Krytonum
$ make

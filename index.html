KRYTONUM OS

BUILD PHASE: IN PRODUCTION
Kernel: Linux 6.12-rc UI: WebShell (HTML5/CSS3/ES14)

Core Concept

Krytonum is an upcoming independent Linux distribution where the entire user space, window manager, and system configurations are executed natively through a hardened, low-overhead JavaScript runtime. No heavy desktop environments. No bloated rendering pipelines.

System Configuration Preview

How system nodes and environments are defined in Krytonum via raw JSON.

/etc/krytonum/init.json 
{
    "system": {
        "hostname": "krytonum-dev-node",
        "runtime": "Velo-WebShell-Core",
        "allow_jit": true
    },
    "display": {
        "engine": "Wayland-Chromium-Minimal",
        "default_compositor": "css-grid-wm",
        "hardware_acceleration": "vulkan"
    },
    "modules": [
        "./ui/statusbar.js",
        "./ui/terminal-emulator.js",
        "./services/network-manager.json"
    ]
}

Production Roadmap (2026)

Phase 1: Kernel & Wayland Binding

Stripping the Linux kernel and establishing the direct bridge between Wayland compositor events and JavaScript bindings. (Completed Q1 2026)

Phase 2: HTML/CSS Window Manager

Current focus. Compiling the core CSS Grid-based window management system and hardware-accelerated DOM rendering. (In Progress)

Phase 3: Public Alpha Source Release

Source code release for independent building. No pre-compiled ISO binaries will be provided at this stage.
